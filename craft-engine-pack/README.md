# KaleidoscopeCookery CraftEngine pack

Copy the `custom` directory into `plugins/CraftEngine/resources/`, then reload or restart the server.

The source archive is the `KaleidoscopeCookery.zip` asset from the
[KaleidoscopeCookery Plugin 1.0.3 release](https://github.com/Nicoppara/KaleidoscopeCookery_Plugin/releases/tag/1.0.3).
Its published SHA-256 digest is
`e51631591fc0b41ef7b6185d3bfaaa8ef796591ce381432d37dc78ebc43a43ab`.

This repository adds the CraftEngine `pack.yml` manifest and maintains the configuration format against the latest
`Xiao-MoMi/craft-engine` `main` branch. The generated server resource pack remains managed by CraftEngine.
